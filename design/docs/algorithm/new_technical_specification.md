# Наименование проекта

Десктопное или веб-приложение для учёта финансов по проектам и сотрудникам компании

## Цель проекта

Реализовать веб-приложение с использованием реляционной базы данные для учёта финансов по проектам и сотрудникам компании

## Исходная информация

* веб-приложение системы контроля и управления проектами Easy Redmine 2018.1.1 с возможностью использования REST API;
* база данных MySQL 5.7 с данными Easy Redmine;
* созданная реляционная база данных для новых данных.

## Что нужно сделать

Необходимо реализовать веб-приложение со своей реляционной базой данных (локальная БД).

### Окно 1 - **Авторизация**

Стартовой страницей будет страница с авторизацией пользователя. Необходимо это для отслеживания действий в системе.
После успешной авторизации будет открываться окно с основными кнопками, при нажатии на каждую из которых будет открываться соответствующая страница.
Основные страницы:

* **З/П сотрудников**;
* **Проекты**;
* **Отчёт по сотрудникам**;
* **Отчёт по проектам**;
* **Статистика по проектам по годам**.

### Окно 2 - **ЗП сотрудников**

[//]: # (Представляет собой [страницу] \( https://www.figma.com/design/YWKZth8mPRX7pnUVQqsmtm/Untitled?node-id=1-7 \) .)

На открывшейся странице необходимо сначала:

1. Выбрать месяц и год, за который необходимо заполнить данные.
2. Нажать "Получить список пользователей".

Ниже появляется таблица со списком сотрудников (экспорт сотрудников с какой-либо активностью за выбранный месяц из Easy Redmine) на один выбранный календарный месяц, где есть возможность вводить вручную (или импортировать из Excel - пока неточно) в столбцы с данными за один выбранный календарный месяц:

* номинальная З/П;
* Доп. З/П;
* Премия квартальная (с опциональным выбором номера квартала и года);
* Доп. премия;
* Отпускные;
* Больничные;
* Командировочные.

По умолчанию шапка таблицы выглядит примерно так:

| ФИО      | Должность | З/П     | Доп. З/П | Премия квартальная | Доп. премия | Отпускные | Больничные | Командировочные |
| -------- | --------- | ------- | -------- | ------------------ | ----------- | --------- | ---------- | --------------- |
| `string` | `string`  | `money` | `money`  | `money`            | `money`     | `money`   | `money`    | `money`         |

Если у сотрудника в предыдущем месяце есть данные по зарплате, премии или др., они будут автоматически заполнены изначально.  
Тут можно отредактировать указанные данные сотрудников или заполнить пустые значения.
Над таблицей есть кнопка **Сохранить**.

Будет возможность сортировать список сотрудников, возможно добавление фильтров (например, по группам из Redmine и др. - необходимо продумать это позже)

Можно сделать экспорт данных в формате файла Excel по кнопке внизу.

### Окно 4 - **Отчёт по сотрудникам**

На данной странице расположена таблица, где отображаются  реальные (расчётные) заработные платы, премии и др. по сотрудникам.

По умолчанию шапка таблицы выглядит примерно так:

<table>
  <tr>
    <td rowspan="2">
      Фамилия
    </td>
    <td rowspan="2">
      Имя
    </td>
    <td rowspan="2">
      Должность
    </td>
    <td colspan="7"; align=center>
      Январь 2026
    </td>
    <td>
      ...
    </td>
    <td rowspan="2">
      Среднее за период
    </td>
  </tr>
  <tr>
    <td>
      З/П
    </td>
    <td>
      Доп. З/П
    </td>
    <td>
      Квартальная премия
    </td>
    <td>
      Доп. премия
    </td>
    <td>
      Отпускные
    </td>
    <td>
      Больничные
    </td>
    <td>
      Командировочные
    </td>
  </tr>
</table>

Значения в столбцах **З/П** и **Доп. З/П** по каждому сотруднику в таблице являются расчётными:

* для сотрудников на полной ставке:
  * **З/П** - З/П сотрудника со страницы [зарплат сотрудников](#окно-2---зп-сотрудников);  
* для сотрудников на неполной ставке:
  * **З/П** или **Доп. З/П** за месяц с учётом отработанных часов, которые рассчитываются таким образом:

$$\frac{(Salary\ or\ AdditionalSalary) \cdot Hours_{employeeMonth}}{NormalHours_{month}},$$

где $Salary$ - номинальная З/П сотрудника, которая вносится на странице [зарплат сотрудников](#окно-2---зп-сотрудников) в столбце **З/П**;  
$AdditionalSalary$ - номинальная дополнительная З/П сотрудника, которая вносится на странице [зарплат сотрудников](#окно-2---зп-сотрудников) в столбце **Доп. З/П**;  
$Hours_{employeeMonth}$ - кол-во отработанных часов сотрудника за данный месяц;  
$NormalHours_{month}$ - кол-во рабочих часов за данный месяц для 40 ч. недели согласно производственному календарю.

Значения **Квартальная премия**, **Доп. премия**, **Отпускные**, **Больничные**, **Командировочные** заполняются автоматически значениями со страницы [зарплат сотрудников](#окно-2---зп-сотрудников) из соответствующих столбцов.

Последним столбцом в таблице является средний доход сотрудника в месяц за показываемый период времени, который автоматически рассчитывается:

$$\frac{SumIncome}{Period},$$

где $SumIncome$ - сумма фактических зарплат, премий, отпускных, больничных и командировочных сотрудников за этот период времени;  
$Period$ - кол-во месяцев отображаемого периода.

Можно сделать экспорт данных в формате файла Excel по кнопке внизу.

### Окно 5 - **Отчёт по проектам**

На данной странице расположена таблица, где показываются данные по бюджетам проектов и их подпроектов.  
Все значения в данной таблице являются нередактируемыми.

Пояснения по значения столбцов:

* **Бюджет на начало месяца** - бюджет проекта на 1 число данного месяца с учётом всех предыдущих доходов и расходов;
* **Доходы** - сумма доходов проекта на 1 число данного месяца;
* **Расходы на З/П** - вычисляется автоматически сумма статей расходов на З/П сотрудников, которые имеют затраченное время на проекте в данном месяце:
  * для сотрудников на полной ставке по формуле:

  $$\frac{Salary \cdot Hours_{projectMonth}}{Hours_{month}},$$

  где $Salary$ - номинальная З/П сотрудника (столбец **З/П** таблицы со страницы [зарплат сотрудников](#окно-2---зп-сотрудников));  
  $Hours_{projectMonth}$ - кол-во отработанных часов сотрудника за данный месяц на конкретном проекте;  
  $Hours_{month}$ - кол-во отработанных часов сотрудника за данный месяц;
  * для сотрудников на неполной ставке по формуле:
  
  $$\frac{Salary \cdot Hours_{projectMonth}}{NormalHours_{month}},$$

  где $Salary$ - номинальная з/п сотрудника (столбец **З/П** таблицы со страницы [зарплат сотрудников](#окно-2---зп-сотрудников));  
  $Hours_{projectMonth}$ - кол-во отработанных часов сотрудника за данный месяц на конкретном проекте;  
  $NormalHours_{month}$ - кол-во рабочих часов за данный месяц для 40 ч. недели согласно производственному календарю;
  
* **Расходы на доп. З/П** - аналогично как и со столбцом **Расходы на З/П**;
* **Расходы на премию квартальную** - сумма статей расходов на квартальные премии сотрудников за этот месяц;
* **Расходы на доп. премию** - сумма статей расходов на доп.премии сотрудников за этот месяц;
* **Расходы на отпускные** - сумма статей расходов на отпускные сотрудников за этот месяц;
* **Расходы на больничные** - сумма статей расходов на больничные сотрудников за этот месяц;
* **Расходы на командировочные** - сумма статей расходов на командировочные сотрудников за этот месяц;
* **Иные расходы** - сумма статей всех остальных расходов за этот месяц;
* **Доходы за период** - сумма доходов проекта за период;
* **Расходы за период** - сумма всех расходов проекта за период.

В таблице можно через кнопки "Фильтры" и "Сортировка" вверху страницы:

* выбрать рассматриваемый временной промежуток (промежуток по умолчанию - текущий квартал);
* упорядочить значения списка проектов и отфильтровать список проектов и подпроектов;
* выбрать какие столбцы атрибутов "Проектов" будут показываться в таблице (Номер проекта, Проект, Наименование в 1С и т.п.).

В таблице отображаются как отдельные проекты, так и проекты с подпроектами.

Правила для проектов (родительских проектов) с подпроектами:

* первым идёт родительский проект, а сразу после него - подпроекты;
* сгруппированы вместе;
* значения столбцов **Стартовый бюджет**, **Бюджет на начало месяца**, **Расходы на З/П** и др. для строки родительского проекта получаются суммированием значения данного родительского проекта с соответствующими значениями подпроектов. Например, если у каждого из трёх подпроектов расходы на З/П равны по 100, а у родительского проекта расходы на З/П составляют 50, то в таблице будет отображено *50 (Всего 350)*.

Внизу справа есть кнопка экспорта данной таблицы в формате Excel и PDF.
