## Описание проекта

Данный проект является десктопным или веб-приложением для учёта финансов по проектам и сотрудникам компании.

## Используемые технологии

* веб-приложение системы контроля и управления проектами Easy Redmine 2018.1.1 с возможностью использования REST API
* база данных MySQL 5.7

|Библиотеки      |
| :------------- |
| Python 3.14.0  |
| Django 6.1     |
